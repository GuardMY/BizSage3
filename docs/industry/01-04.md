# 农林牧渔 - 林业与木材行业知识库

## 1. 行业定义与边界

**农林牧渔**以土地、水域、生物资产或森林资源为生产基础，产出初级农产品并通过加工、流通或服务实现价值。经营结果受自然条件、产品周期和价格波动共同影响。本篇聚焦**林业与木材**：覆盖林木培育、采伐、木材初加工和林下资源经营，周期长，需同时管理林地、采伐计划、生态约束与库存。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以农林牧渔行业中的林业与木材产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：种苗、饲料、肥料、农药、兽药、农机、温室或养殖设施、土地/水域使用权，以及金融和保险服务。采购不仅看价格，还要看批次质量、交付时点和追溯能力。针对林业与木材，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

收购商、加工厂、批发市场、商超、电商和餐饮客户。按规格、等级、交期和安全文件验收。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

计划与地块建档 -> 投入品采购 -> 生产巡检 -> 采收分级 -> 仓储销售 -> 结算复盘。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：生产负责人、农艺师/兽医、基地管理员、采购、质检、销售和仓储人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。
