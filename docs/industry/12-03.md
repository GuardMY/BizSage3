# 医药健康 - 医疗器械行业知识库

## 1. 行业定义与边界

**医药健康**覆盖药品、医疗器械和医疗服务，产品与服务直接影响生命健康，研发、注册、质量体系、临床/诊疗流程和合规经营是基本盘。本篇聚焦**医疗器械**：提供诊断、治疗、监护、耗材和家用医疗设备，注册证、临床适配、经销准入和售后培训影响销售。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以医药健康行业中的医疗器械产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：原料药、辅料、试剂、芯片、精密材料、生产设备、CRO/CMO、医院科室、医护人才和冷链服务。供应商需要符合质量体系与可追溯要求。针对医疗器械，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

医院、药房、经销商、基层机构、支付方、患者和健康管理客户。准入、临床价值、支付、质量和服务共同影响增长。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

研发立项 -> 注册/验证 -> 质量生产 -> 准入交付 -> 使用随访 -> 不良事件与改进。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：研发医学、注册、质量、生产、供应链、准入销售、医护、客服和合规人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。

## 7. 运营指标与分析口径

首批建议指标如下，系统中应配置计算口径、时间范围、责任人和数据来源：

| 指标 | 建议口径 |
| --- | --- |
| 注册周期 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 批次放行率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 产品覆盖率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 服务人次 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 不良事件率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |

## 8. 常见风险与控制

| 风险主题 | 控制建议 |
| --- | --- |
| 质量安全 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 注册失败 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 隐私泄露 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 商业贿赂 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 冷链失效 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |

对医疗器械尤其需要关注其产品/服务特性、关键资源约束、客户集中度和现金流周期，不把通用行业做法直接当成企业事实。

## 9. 数字化与系统录入要点

- **组织与业务标签**：行业“医药健康”、子行业“医疗器械”、业务模式、客户类型、区域、经营阶段和责任组织。
- **经营对象**：按本行业实际选择产品/SKU、项目、合同、订单、批次、设备、资产、门店、站点或服务对象，并设置唯一编号。
- **过程事件**：需求、报价、采购、生产/交付、质检/验收、库存、物流、服务工单、变更、异常、开票和回款。
- **诊断字段**：计划值、实际值、差异值、差异原因、责任人、改进动作、截止日期、验证结果和关联凭证。
