# 新能源 - 风电行业知识库

## 1. 行业定义与边界

**新能源**围绕光伏、风电、新能源发电和氢能等清洁能源技术，覆盖设备制造、项目开发、建设、并网和长期运营，收益高度依赖资源条件与电价机制。本篇聚焦**风电**：包括风机整机、零部件、风场开发建设和运维，资源测算、吊装窗口、设备可利用率与海陆差异明显。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以新能源行业中的风电产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：硅料硅片、电池组件、风机、电解槽、储能系统、土地/海域、并网设备、设计施工和金融资本。供应商锁价、质量保证和交付窗口十分重要。针对风电，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

电网、售电公司、工商业用户、能源投资方、园区和碳资产客户。发电量、并网时点、可利用率、运维和现金流决定价值。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

资源评估 -> 审批并网 -> 设计采购施工 -> 调试投产 -> 发电交易 -> 运维更换。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：资源开发、投资、工程、并网交易、运维、设备质量、EHS和碳管理人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。

## 9. 数字化与系统录入要点

- **组织与业务标签**：行业“新能源”、子行业“风电”、业务模式、客户类型、区域、经营阶段和责任组织。
- **经营对象**：按本行业实际选择产品/SKU、项目、合同、订单、批次、设备、资产、门店、站点或服务对象，并设置唯一编号。
- **过程事件**：需求、报价、采购、生产/交付、质检/验收、库存、物流、服务工单、变更、异常、开票和回款。
- **诊断字段**：计划值、实际值、差异值、差异原因、责任人、改进动作、截止日期、验证结果和关联凭证。
