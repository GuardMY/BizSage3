# 教育培训 - 高等与继续教育行业知识库

## 1. 行业定义与边界

**教育培训**通过课程、师资、学习服务和评价体系提供知识与技能提升，产品交付高度依赖内容质量、教学过程、学习结果和合规收费。本篇聚焦**高等与继续教育**：服务高校、成人和终身学习者，专业建设、教学资源、招生质量、学籍服务和学习支持决定长期价值。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以教育培训行业中的高等与继续教育产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：课程内容、教材版权、教师、教室、实验设备、学习平台、招生渠道和测评服务。教师与内容的稳定性、适配性和合规性是供应基础。针对高等与继续教育，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

学生、家长、企业、学校、政府和职业学习者。客户关注目标、教学效果、时间、服务响应、证书和退费规则。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

需求设计 -> 招生适配 -> 排课开班 -> 教学辅导 -> 测评反馈 -> 续班就业与退费复盘。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：教研、教师、班主任/顾问、招生、教务、运营、督导、客服和合规人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。

| 退费率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |

## 8. 常见风险与控制

| 风险主题 | 控制建议 |
| --- | --- |
| 教学质量 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 虚假宣传 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 教师流失 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 退费现金流 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 隐私保护 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |

对高等与继续教育尤其需要关注其产品/服务特性、关键资源约束、客户集中度和现金流周期，不把通用行业做法直接当成企业事实。

## 9. 数字化与系统录入要点

- **组织与业务标签**：行业“教育培训”、子行业“高等与继续教育”、业务模式、客户类型、区域、经营阶段和责任组织。
- **经营对象**：按本行业实际选择产品/SKU、项目、合同、订单、批次、设备、资产、门店、站点或服务对象，并设置唯一编号。
- **过程事件**：需求、报价、采购、生产/交付、质检/验收、库存、物流、服务工单、变更、异常、开票和回款。
- **诊断字段**：计划值、实际值、差异值、差异原因、责任人、改进动作、截止日期、验证结果和关联凭证。
