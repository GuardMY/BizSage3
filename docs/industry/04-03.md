# 家居建材 - 家装服务行业知识库

## 1. 行业定义与边界

**家居建材**提供家具、装饰材料、家装工程和家居零售服务，订单往往同时包含产品、设计、交付、安装和售后，交付协同决定客户体验。本篇聚焦**家装服务**：为家庭或项目提供设计、施工、主材整合和交付服务，项目变更、工期协同与客户验收决定毛利。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以家居建材行业中的家装服务产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：木材、人造板、石材、金属、玻璃、五金、涂料、卫浴、电器、设计软件、安装工和物流服务。供应商质量、交付尺寸和安装适配性必须前置确认。针对家装服务，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

房地产项目、装修公司、设计师、门店、整装客户和家庭消费者。客户关注预算、效果、工期、安装和售后。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

获客量房 -> 方案报价 -> 选材拆单 -> 采购生产 -> 配送安装 -> 验收售后。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：设计师、量房顾问、项目经理、拆单、采购、计划、安装和客户服务人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。

## 7. 运营指标与分析口径

首批建议指标如下，系统中应配置计算口径、时间范围、责任人和数据来源：

| 指标 | 建议口径 |
| --- | --- |
| 报价毛利率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 订单变更率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 准时交付率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 一次验收率 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |
| 项目回款周期 | 按订单、项目、批次或资产分层统计，结合质量和现金结果解释 |

## 8. 常见风险与控制

| 风险主题 | 控制建议 |
| --- | --- |
| 尺寸设计错误 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 材料涨价 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 交付延期 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 安装返工 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |
| 回款拖延 | 设置责任人、检查频率、触发阈值、处置动作和复盘证据 |

对家装服务尤其需要关注其产品/服务特性、关键资源约束、客户集中度和现金流周期，不把通用行业做法直接当成企业事实。

- **组织与业务标签**：行业“家居建材”、子行业“家装服务”、业务模式、客户类型、区域、经营阶段和责任组织。
- **经营对象**：按本行业实际选择产品/SKU、项目、合同、订单、批次、设备、资产、门店、站点或服务对象，并设置唯一编号。
