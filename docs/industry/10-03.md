# 电气设备 - 工业自动化行业知识库

## 1. 行业定义与边界

**电气设备**提供发输配电、工业控制、连接与储能设备，产品既有标准化制造，也有工程配套和现场服务，可靠性与安全认证影响长期订单。本篇聚焦**工业自动化**：提供PLC、驱动、控制柜、机器人和产线集成，价值来自节拍改善、系统集成、调试和持续服务。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以电气设备行业中的工业自动化产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：铜铝导体、钢材、绝缘材料、功率器件、继电器、控制芯片、电芯、机柜、软件和试验服务。关键件要有认证、寿命和供应商变更控制。针对工业自动化，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

电网、发电企业、工厂、建筑、数据中心、轨道交通和新能源项目。技术协议、认证、安装和并网投运影响验收。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

项目需求 -> 方案投标 -> 选型/BOM -> 制造 -> 型式试验 -> 发货安装并网。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：电气工程、售前投标、项目、采购计划、装配试验、质量和现场服务人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。
