# 钢铁有色 - 再生资源行业知识库

## 1. 行业定义与边界

**钢铁有色**从矿石、废钢或再生金属出发，经冶炼、轧制、铸造和深加工形成钢材及有色金属产品，资本密集、能耗高、价格周期明显。本篇聚焦**再生资源**：回收、分拣、拆解和再加工废金属及其他可利用材料，货源组织、品质分选、合规运输和价格风险是核心。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以钢铁有色行业中的再生资源产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：矿石、焦煤、废钢、精矿、合金、氧气、辅料、能源、冶金设备和运输。采购成本、原料品位、库存港存和供应稳定性影响吨钢/吨金属成本。针对再生资源，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

建筑、汽车、机械、家电、能源、电子、包装和金属加工客户。按牌号、规格、炉次和质保书交付。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

原料配矿 -> 冶炼精炼 -> 连铸/铸造 -> 轧制加工 -> 检验包装 -> 仓储配送结算。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：冶炼/轧制工程师、调度、设备能源、质量、采购、物流、销售和成本人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。
