# 物流仓储 - 冷链物流行业知识库

## 1. 行业定义与边界

**物流仓储**通过揽收、运输、仓储、分拣、配送和供应链协同实现货物履约。成本取决于网络密度、订单结构、装载率、仓效和异常率。本篇聚焦**冷链物流**：服务食品、医药和生鲜的温控运输与仓储，温度连续性、时效、能源成本、包装和异常理赔尤为关键。其经营边界通常包括产品/服务设计、资源组织、交付和客户运营；若企业同时经营其他板块，应按业务单元拆分收入、成本、资产和客户数据。

## 2. 典型业务模式

- **价值交付**：以物流仓储行业中的冷链物流产品或服务为核心，兼具标准化交付、定制项目、渠道交易或持续运营等形态。
- **收入来源**：主要来自产品销售、项目合同、服务费、佣金、订阅、租赁或增值服务，应区分折扣、返利、退款和代收款。
- **经营重点**：同时管理客户需求、资源投入、交付质量、价格毛利和回款，不能只用收入规模判断经营健康度。

## 3. 上游与采购管理

该行业主要上游包括：车辆与运力、仓库、场站、包装耗材、信息系统、司机和外包承运商。合作方需按线路、车型、服务等级和安全能力管理。针对冷链物流，采购应记录供应商资质、价格账期、交付承诺、验收结果、批次/序列号和替代方案，重点识别单一供应、长交期与质量认证约束。

## 4. 下游与客户运营

电商、制造、零售、医药、餐饮、跨境贸易和个人客户。客户关注时效、签收、损坏率、温控、可视化和理赔。客户运营要串联线索/需求、报价、合同、订单、履约、验收、开票、回款和售后；应按客群、区域、渠道和业务单元分析转化、贡献毛利、服务成本与流失原因。

## 5. 核心运营流程

网络规划 -> 订单揽收 -> 入库分拣 -> 仓配运输 -> 签收 -> 对账理赔复盘。每个节点都应保留计划值、实际值、责任人、异常原因和改进结果；变更要同步影响的价格、成本、交期和风险。

## 6. 关键岗位与协作关系

典型岗位包括：网络规划、仓储、运输调度、司机、客户经理、客服理赔和结算人员。销售承诺、采购变更、交付验收、质量安全和财务结算应在同一业务对象下协同，关键审批和异常关闭需要留痕。
